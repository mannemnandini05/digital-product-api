# Digital Product Store

A full-stack e-commerce application for browsing, purchasing, and managing digital products.

## Tech Stack

### Backend
- FastAPI
- Python
- SQLAlchemy
- SQLite
- Pydantic
- JWT Authentication
- Stripe

### Frontend
- React
- Vite
- Tailwind CSS
- Axios
- React Router
- React Toastify

## Features

- User Registration and Login
- JWT Authentication
- User Profile
- Product Listing
- Product Search
- Product Pagination
- Product Details
- Shopping Cart
- Checkout with Stripe
- Order Management
- Admin Product Management
- Admin Order Management
- Admin Statistics
- SQL Reports
- API Testing with Pytest
- Swagger API Documentation
